# v5.3.1 (In Development)

## Changes

1. `RenderEngine` now declares a default response content type, so using `engineType` no longer requires
   a separate `@Produces`. Built-in JSON and text renderers declare `application/json` and `text/plain`.
   Custom implementations must implement `defaultContentType()`, returning `null` when unspecified.
2. `@Bean` in `hasor-config` now supports concrete classes, registering business Beans from configured
   scan packages without individual `bindType` calls. See [Java annotation configuration](../../guides/core/conf/java-config.md).
3. Add `AnnotationInjector` and `ApiBinder.bindAnnotationInjector(...)` for custom annotation field
   injection before Bean initialization. See [Custom annotation injection](../../guides/core/ioc/by_annotation.md).
