# v3.0.2 (2017-01-30)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-core</artifactId>
    <version>3.0.2</version>
</dependency>
```

## Scope

- Core Providers and Web binding and encoding

## Changes

- Added
  - Add `ProviderType` to describe the return type of a Provider.
  - Add `findBindType` to `MappingToBuilder`.
- Fixed
  - Fix exceptions in `RuntimeFilter` when request and response encodings are not configured.
