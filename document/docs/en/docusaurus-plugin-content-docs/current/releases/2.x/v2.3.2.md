# v2.3.2 (2016-05-29)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-core</artifactId>
    <version>2.3.2</version>
</dependency>
```

## Scope

- Core plugin assembly, events, and result messages

## Changes

- Improved
  - Invoke `handleComplete` after event handling finishes.
  - Add Message-related methods to Result.
  - Check configuration when initializing built-in plugins and assemble only the features actually in use.
