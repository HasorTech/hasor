# v4.1.9 (2020-06-29)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-all</artifactId>
    <version>4.1.9</version>
</dependency>
```

## Scope

- Web HTTP parameters and Core SPI lookup

## Changes

- Added
  - Add `HttpParameters` for accessing request parameters through static methods.
  - Add `hasSpi` and `hasJudge` to check whether SPI listeners and arbitrators are registered.

## Upgrade notes

- The Header parameter reading issue in this version is fixed in v4.1.10.
