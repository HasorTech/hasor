# v5.2.1 (2026-09-23)

5.2.1 是开发阶段的版本记录，相关 API 随 5.3.0 正式发布。以下依赖使用 5.3.0。

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-core</artifactId>
    <version>5.3.0</version>
</dependency>
```

## 影响范围

- Core、Config 和文档。

## 更新内容

- 新增
  - 增加 `dependsOn(...)` 和 `@DependsOn`，支持声明 Bean 初始化依赖。
  - 增加 `ApiBinder.getProvider(name, type)`，按名称和类型获取 Provider。
  - 文档站增加中英文 `llms.txt`，提供项目介绍与使用指南索引。
- 优化
  - Provider 在容器初始化通知完成后即可使用。
  - 统一中英文文档编号与导航。
