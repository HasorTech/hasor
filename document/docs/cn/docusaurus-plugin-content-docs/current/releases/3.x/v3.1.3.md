# v3.1.3 (2017-02-23)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-core</artifactId>
    <version>3.1.3</version>
</dependency>
```

## 影响范围

- Core 绑定查询与事件线程

## 更新内容

- 优化
  - 事件管理器支持通过构造参数指定线程名称。
- 修复
  - 修复 `AppContext.getBindIDs`、`getNames` 始终返回空值的问题。
